# HBFSim v0.7.0–v0.7.3 Semantic Convergence

v0.7 is a correctness and ownership release. It does not add a new external
media feature; it makes the v0.6 Host-managed behavior unambiguous.

## v0.7.0: Rewrite and retention correctness

- A destination Program Failure records the actual failed destination slot,
  rather than the end of the planned range.
- `HostRewriteReason` separates Program Failure replay, Refresh, and Wear
  Leveling. Their DES traffic uses `HOST_REPLAY`, `HOST_REFRESH`, and
  `HOST_WEAR_LEVEL` independently.
- `BlockMeta` lazily records program time per programmed Page. Read RBER now
  uses the target Page's age, bounded by the most recent block refresh time.

## v0.7.1: Zone/Wear v2

Zone state is split into three concepts:

```text
LogicalZoneStats       user_write hotness
ZoneManager mapping    logical zone <-> physical zone (bijection)
PhysicalZoneWear       program/erase and current block P/E distribution
```

Logical Zones are contiguous configured LPN ranges; they no longer alias by
`% zone_count`. Physical Zones are contiguous ranges of physical Stripe IDs.
`remap(logical, physical)` swaps the old owner of the target physical Zone.
Maintenance writes do not alter user-hotness telemetry.

Wear policy now requires both minimum user-write activity and a configurable
P/E imbalance before selecting a migration. `wear_leveling.min_user_writes`
and `wear_leveling.min_pec_delta` control this hysteresis.

## v0.7.2: Mapping contract

`IMediaManagementMapping` is the narrow contract used by Host rewrite flows:
sequential destination placement, hole reservation, migration commit/abort,
and generation-checked Stripe addressing. `StripeMappingTable` is its current
adapter. Host Rewrite no longer directly requires the concrete table type,
which leaves a clean insertion point for a future Spec-native mapping adapter.

## v0.7.3: HostRewriteEngine

`HostRewriteEngine` owns rewrite plans, identities, reasons, and lifecycle
state. `Simulator` remains the DES event owner and supplies Host link/NAND
events. This keeps execution timing in the kernel while moving Host rewrite
semantics out of the CopyEngine model.

## Validation

`test_v070_semantics` checks Page-specific retention age, Zone swap
invariants, physical P/E ownership, and rejection of LPNs outside configured
Logical Zones. Existing Host replay and Host management tests verify source
traffic and completion counts for Replay, Refresh, and Wear Leveling.
