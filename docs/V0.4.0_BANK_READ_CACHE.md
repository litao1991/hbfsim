# HBFSim v0.4.0 Bank and Read Cache

v0.4.0 在 Die 与 Plane 资源之间增加可配置 Bank 命令域。Plane 通过 `plane % banks_per_die` 归属 Bank，`banks_per_die` 必须整除 `planes_per_die`。

每个 Bank 在规范 Profile 下拥有两个 4KiB Read Cache Entry，使用确定性 LRU：

```text
Read → Pending DLU → Bank Cache
                     ├─ Hit  → DataFabric → D2H
                     └─ Miss → NAND Sense → Fill → DataFabric → D2H
```

Program、Erase、Retirement 和映射 generation 变化会失效相关条目。`summary.csv` 输出 hit、miss、eviction、hit bytes 和 hit ratio。研究 Profile 默认关闭 Read Cache 并继续使用 Die command timing，保持历史实验兼容。
