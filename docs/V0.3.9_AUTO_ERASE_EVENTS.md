# HBFSim v0.3.9 Page-0 Auto-Erase Events

Page-0 Auto-Erase 不再压缩成一个 `NandProgramDone`：

```text
Data In → AutoEraseDone → tWHR → Program → ProgramDone
```

Block bitmap、program frontier 和 erase count 仅在 Erase 成功完成时更新。Erase Failure 和 P/E Retirement 在该完成点返回；Program 不再执行。统计分别记录 Auto-Erase 次数及其 array service。
