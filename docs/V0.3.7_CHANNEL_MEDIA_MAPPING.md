# HBFSim v0.3.7 Channel Media Mapping

规范 Profile 使用独立于研究 `mapping.policy` 的 `hbf.media_mapping.policy`。

- `linear` 保留 v0.3.5 Channel-local Page→Block→Plane 顺序；
- `fine_stripe` 先在 Channel-owned Plane Pool 内轮转 Plane，再推进 Page/Block row；
- `HbfSystem` 只构造一个 `HbfChannelDomain`，Mapper 与 Router 引用同一地址事实来源；
- Profile factory 对规范路径默认选择 `fine_stripe`，resolved config 固化最终策略。

Channel Pool 当前是 Plane 级隔离；跨 Channel 的 Die/Bank 共享由 v0.4.0 Bank 模型显式表达。
