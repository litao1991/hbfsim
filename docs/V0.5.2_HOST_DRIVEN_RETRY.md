# HBFSim v0.5.2 Host-driven Read Retry

HBF/AI profile 默认启用 `hbf.host_driven_read_retry`。当 read 的 ECC 不可纠正且仍有
retry budget 时，设备返回 `UncorrectableEccRetryRequired`；`HbfResponse.error` 的
`retry_stage` 是 Host 下一次应提交的 stage。

trace 的可选第九列为 `read_retry_stage`。例如一个 HBF Read 的原始请求为：

```text
0,read,0,64,0,0,0,0,0
```

若其 response 的 retry stage 为 `1`，Host 重发：

```text
1000,read,0,64,0,0,0,0,1
```

stage 直接传递给 reliability model，因此根据 `retry_ber_multiplier` 改变 RBER。
超过 `max_read_retries` 的 stage 在 frontend 被拒绝；最后一个可用 stage 仍不可纠正
时返回最终 `UncorrectableEcc`。`media_research` 保持原来的 device automatic retry，
以免破坏历史研究 trace。
