# HBFSim v0.5.3 Spec Block Replay

Host-managed Program Failure 不再只有一个泛化 failure notice。每次失败都会生成
`ReplayPlan`，包含源 Stripe identity/generation、failed PPA/slot、已提交 slot 数和
Host 应重新提供的 payload 字节数。`Simulator::replay_plans()` 可供 Host 模型读取。

该 plan 只描述 Host replay 的输入，不会自动调用 research CopyEngine/GC 路径；因此
Host 可以按协议决定数据重建、目标放置和重发时机。
