# HBFSim v0.4.3 Media / Controller Boundary

v0.4.3 收口每 Plane 的 ownership，使 NAND 介质状态与 Controller 调度状态不再
共享同一个可变对象。

`PlaneMediaState` 只保存 NAND 可观测状态：block 元数据与 page bitmap、array
`ready_at`、以及 data-register 占用。它由 `NandMediaSystem` 管理，并提供
`begin_read`、`begin_program`、`begin_erase`、`complete_program`、
`fail_program`、`complete_erase`、`reserve_program_hole`、array-ready 和
data-register 操作。由此 Program Failure、Erase Failure、Refresh、Auto-Erase
以及 Copy 的 hole reservation 都遵循同一介质转换路径。

`PlaneControllerState` 只保存 source-aware 队列、busy/active/suspended/cached
命令与 read-streak。它归 `BaseDieController` 所有；执行 credit、dispatch cursor、
wakeup 及 program-ready 仍归 `ControllerExecutionState`。

`Simulator` 仍拥有模拟时间、event queue 和 Request/SubRequest 生命周期。它通过
Controller 选择命令、通过 Media System 改变介质状态，因而不会成为新的 NAND 状态
owner。Copy 的 transport/event orchestration 暂仍由 kernel adapter 执行，但其
job 状态保留在 `CopyEngine`；后续 Batch Read 与 Host Retry 可以在这条边界之上增加。

本版本是行为保持重构：不改变 trace、配置、事件类型或统计格式。
