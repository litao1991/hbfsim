# HBFSim v0.5.1 Batch Read Protocol

Batch Read 是显式 opt-in 行为。配置如下：

```yaml
hbf:
  batch_read:
    enabled: true
    aggregation_window_ns: 100
    max_pages: 8
```

CSV trace 在既有 `timestamp,op,address,size,stream,axi_id,axi_port` 之后可选第八列
`batch_hint`（`0` 或 `1`）。只有 `batch_hint=1` 的 Read cache miss 进入 Batch 路径；
cache hit、Single Read、Write、Erase 和 Refresh 均不改变行为。

同一物理 Bank 的 hinted pages 在第一个 page 到达后的 aggregation window 内收集。
到期时按 `max_pages` 形成一个或多个 batch；它们进入该 Bank 的 FIFO Sense queue。
queue front 被发射到现有 NAND Read 事件路径，Sense 完成才释放下一个 front。不同 Bank
各有队列，所以可独立推进。

`summary.csv` 新增 `batch_read_emissions`、`batch_read_pages` 和
`batch_read_aggregation_delay_ns`。该延迟是 page 在聚合窗口中等待的总时间，不包括
既有的 NAND queue、array、fabric 或 Host 数据传输时间。
