# HBFSim v0.3.4 HBF Status

v0.3.4 将 Host 可见错误从 C++ 异常迁移到 `HbfResponse`。模拟器内部不变量，例如陈旧
generation、损坏的队列顺序或没有对应 issue 的 AXI completion，仍然抛出异常。

## Write Status

| Code | Semantic status |
|---:|---|
| `0x1` | Invalid Address |
| `0x2` | Overlap Address |
| `0x3` | Invalid User Field |
| `0x4` | Max Pending DLU Reached |
| `0x5` | DLU Accumulation Timeout |
| `0x6` | Write Order Violation |
| `0x7` | Program Failure / Host Replay Required |
| `0x8` | Reduced Capacity |
| `0x9` | Die Temporarily Blocked |

## Read Status

| Code | Semantic status |
|---:|---|
| `0x1` | Invalid Address |
| `0x2` | Temporarily Restricted |
| `0x3` | Invalid User Field |
| `0x4` | UECC / Refresh Required |
| `0x5` | CECC / Refresh Required |
| `0x6` | UECC / Read Retry Required |
| `0x7` | Read Erased Page |
| `0x8` | Reduced Capacity |
| `0x9` | Die Temporarily Blocked |
| `0xA` | Read Pending Write |

`HbfResponse.protocol_status_code` 保存编码，`HbfStatus` 保存不依赖传输格式的语义；
`HbfErrorInfo` 可以携带逻辑/物理地址、retry stage、retirement granularity 和原因。
`Simulator::responses()` 按 AXI 可见顺序返回响应。

验证入口为 `tests/spec/test_status.cpp`。
