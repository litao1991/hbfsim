# HBFSim v0.4.2 Controller Execution State

v0.4.2 是 v0.4.1 ownership 重构的第一步收口：保持时序、事件类型、配置和
统计输出不变，将设备调度执行状态从 `Simulator` 迁入 `BaseDieController`。

`ControllerExecutionState` 现在拥有：

- 每 Die、每 Stack 的 active-plane credit；
- 每 Stack 的 round-robin dispatch cursor；
- 去重后的 dispatch wake deadline；
- 等待 Data In 完成的 program-ready 队列。

`Simulator` 继续是确定性 kernel：它拥有模拟时间、`EventQueue`、Request/SubRequest
生命周期和统计协调。Controller 的完整 dispatch state machine 将在后续迭代通过
runtime/effect 边界迁移，避免 controller 反向依赖 kernel。

同一版本还将完成 Program、Program Failure、Erase、页失效、读失败标记和 Refresh
时间戳的介质 bitmap/block-state 转换收口到 `NandMediaSystem`。逻辑到物理映射提交
仍由 `AddressMapper` 负责；这样不把 L2P ownership 混入 media。

本版本不改变对外功能。`component_boundaries` 验证 Controller execution state 的
拓扑尺寸；全量 CTest、规范测试、Model Validation 和固定 trace 输出比较是发布门禁。
