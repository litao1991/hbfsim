# HBFSim v0.5.0 Batch Read Foundation

v0.5.0 先定义 Batch Read 的资源边界，而不提前改变普通 Read 的输出。

每个 `Request` 与 `SubRequest` 均携带 `ReadType`。`Single` 是默认值，完全沿用
既有 NAND Read、Read Cache 和 DataFabric 路径；`Batch` 预留给后续聚合后的读命令。

每一个物理 Bank 现在拥有一个 `BankSenseQueue`。队列是严格 FIFO：只能从 front
完成，跨 Bank 不共享队列。因此它可表达“同一 Bank 的 Batch Sense 有序、不同 Bank
可以独立推进”的资源关系，同时不会把它错误地并入命令间隔或 Read Cache。

v0.5.1 将在该基础上增加 host hint、聚合窗口、boundary 和批量发射；届时只有被
明确标为 `Batch` 的命令会消耗这个队列。此版本不新增 trace 字段、配置开关或统计
指标，以确保普通 Read 的时序与 v0.4.3 一致。
