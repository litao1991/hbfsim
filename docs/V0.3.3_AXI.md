# HBFSim v0.3.3 Transaction-Level AXI

v0.3.3 在每个 HBF Channel 内增加 1、2 或 4 个虚拟 AXI Port。当前抽象层级仍是
transaction，不模拟逐周期 `valid/ready` 或 UCIe Flit。

## Port 地址域

Channel Local Address 按 `axi.port_interleave` 再次交织，得到：

```text
Channel Local Address
  → AXI Port ID
  → AXI Port Local Address
```

交织粒度支持 64B–4KiB 的 2 的幂。Trace 可以增加 `axi_id` 和 `axi_port`；省略 Port
时由地址自动推导，显式 Port 与地址域不一致时返回 `InvalidAddress`。

## Ordering 与 Flow Control

`AxiOrderTracker` 以 `(Channel, Port, AXI ID)` 为键记录 issue FIFO：

- 同一 ID 的响应严格按发射顺序释放；
- 不同 ID 可以乱序完成；
- `axi.max_outstanding_per_id` 提供事务级背压；
- 非法 Channel、Port 或 ID 返回 `InvalidUserField`。

Host command、H2D 和 D2H 仍复用现有 `HostInterface` 带宽资源，因此 AXI ordering
与链路竞争会同时反映在完成时间中。

验证入口为 `tests/spec/test_axi.cpp`。
