# HBFSim v0.3.2 Channel Domain

v0.3.2 将 Host Channel 从单纯带宽资源升级为地址与 NAND 资源所有权域。

## 地址转换

`HbfChannelDomain` 提供可逆转换：

```text
stripe  = global_address / channel_interleave
channel = stripe % channel_count
local   = stripe / channel_count * channel_interleave + offset
```

`global_address(ChannelAddress)` 执行逆转换并检查设备容量。规范 Profile 支持 64B、
128B、256B、512B、1KiB、2KiB 和 4KiB interleave。

## 独立 NAND Pool

规范 Profile 要求 `hbf.channel_count` 与 Host Channel 拓扑一致，并要求每 Stack 的
Plane 数可以被 Channel 数整除。`AddressMapper::map_channel_read()` 和
`prepare_channel_write()` 只在对应 Channel 的连续 Plane Pool 内生成 PPA，且
`PhysicalAddr.channel` 保留所有权信息。

这保证：

```text
Request.channel == PPA.channel
```

研究 Profile 保持原有 LPN/Stripe Mapper，不改变既有实验结果。

验证入口为 `tests/spec/test_channel.cpp`。
