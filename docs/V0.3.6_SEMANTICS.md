# HBFSim v0.3.6 Semantic Convergence

v0.3.6 统一程序内与 YAML Profile 默认值，并将协议状态和完成性质分开。

- `Config::for_profile()` 与 `apply_profile_defaults()` 是唯一 Profile 默认入口；
- `HbfCompletionClass` 区分 Success、Advisory、RetryRequired 和 Failed；
- CECC Refresh Required 保持非零协议状态，但数据有效且不计入失败请求；
- Pending DLU 容量压力和聚合超时归类为 Retry Required；
- `HbfProtocolValidator` 集中检查 64B 对齐、4KiB 上限及 Channel/Port/Page 边界。

协议状态码保持 v0.3.4 编码，不因统计分类而改变。
