# HBFSim v0.3.8 DLU Observability

每个完成 DLU 累计所有贡献 fragment 的：首末到达时间、fragment 数、H2D wait 和 H2D service。`summary.csv` 与 `dlu_summary.csv` 输出 assembly mean/p95/p99、timeout、overlap、capacity rejection、forwarded/pending Read 以及 H2D 总成本。

Timeout 使用 `(deadline, channel, local_base, generation)` 最小堆。完成后遗留的旧 heap entry 由 generation 惰性丢弃，避免每个 timeout 扫描整个 Pending 表。
